# Heidi Laurent – Portfolio & Resume Website

A modern portfolio website built to showcase my software engineering projects, technical skills, and professional experience. The site is designed to present real client and product work in a clean, responsive format for recruiters, hiring managers, and collaborators.

## Overview

This project serves as my personal portfolio and resume site. It highlights selected web and software projects, provides a downloadable resume, and gives visitors an easy way to learn about my background and get in touch.

## Features

- Responsive design for mobile, tablet, and desktop
- Project showcase with featured work and summaries
- Resume download
- Contact and collaboration call-to-action sections
- Professional visual design with a structured layout

## Featured Projects

- **SocialBright** – HIPAA-compliant SaaS platform
- **DipVault** – Mobile app for inventory and look tracking
- **Kubat Realty** – Client website project

## Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Deployment:** Planned for AWS

## Local Development

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
```

### Run the development server

```bash
npm run dev
```

Then open the local URL shown in your terminal.

## Build for Production

```bash
npm run build
```
